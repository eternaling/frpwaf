永久黑名单

白名单命中的 IP 不受上述自动封禁影响（需已启用白名单开关）；CC 检测依赖 frp NewUserConn 回调，仅对 https/tcpmux 代理生效（http 类型不触发回调，纯 http 代理请以限速/名单手段为主）；敏感服务检测仅针对非 HTTP 类代理，代理名按分隔符匹配关键字（ssh / mysql / redis / rdp / mongo / postgres / elastic / telnet / smb / vnc / ftp），wordpress 这类含子串的普通名不会误判。爆破封禁在黑名单开关关闭时自动降级为临时封禁。

代理级冷却拦截 分布式突发处置，默认关闭

误伤提示：出口 IP 变化的真实用户（移动网络切换、动态 IP、CDN 回源）可能被拒。建议先在「连接日志 → 突发观测」观察 1-2 天，确认流量性质且可接受偶发误伤后再启用；白名单 IP 不受影响。
