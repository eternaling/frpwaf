# 09 · 认证与安全

## 1. 管理面板认证

### 1.1 默认账号

- 默认 `admin` / `123456`（`config.DEFAULTS`）。
- **安装后请立即修改**（面板「设置」页，或宝塔插件端）。
- 用户名规则：≥2 位，字符集 `^[A-Za-z0-9_.@-]+$`。
- 密码规则：≥4 位。

### 1.2 会话令牌（`app/auth.py`）

```
token = base64url(payload).HMAC-SHA256(payload, secret)
payload = {"u": user, "exp": 过期时间戳}
```

- 签名密钥 `secret`：首次生成（`secrets.token_hex(32)`）后**固定**。
- 有效期 `SESSION_TTL = 12 小时`。
- 校验用 `hmac.compare_digest`（**恒定时间比较**，防时序侧信道）。
- 无需数据库；进程重启后旧会话**仍有效**（secret 固定），除非改密/换 secret。

### 1.3 Cookie

- 名称 `frpwaf_sid`；
- 属性 `Path=/; HttpOnly; SameSite=Lax`；
- **`Secure` 默认不加**：面板走明文 HTTP（7080），若加 `Secure` 浏览器在
  `http://` 下不会回传 Cookie，会「登录成功却立刻 401」。仅当请求经 HTTPS
  （反向代理设 `X-Forwarded-Proto: https`）或配置显式 `cookie_secure=true` 时才加。

### 1.4 登录限速（`daemon` 内存）

- 窗口 300 秒内失败 **10 次** → 锁定 **300 秒**（按来源 IP）。
- 锁定期间登录返回 `429`（提示剩余秒数）。
- 失败响应前 `sleep(0.3)` 降低爆破速率。
- 成功登录清除该 IP 计数；字典有界增长（>5000 时清理过期项）。
- 登录成功/失败/被限速均写运行日志。

## 2. 密码 / 账号修改

两端逻辑一致（`auth.change_credentials` 与 `frpwaf_main.change_admin_pwd`）：

- `old`（原密码）**必填校验**，用 `hmac.compare_digest`；
- 可选 `old_user`（原用户名）二次校验；
- `new_user`（新用户名）可选；`new`（新密码）可选；二者不可都空。

## 3. 密钥 / 密码保护

### 3.1 文件权限

- `data/frpwaf.json`：`chmod 600`（含 `admin_password`、`secret`、`ai_api_key`）。
- `data/frpwaf.db`（+ `-wal`/`-shm`）：`chmod 600`。
- 插件安装时 `.py`/`.json`/`index.html` 置 `600`。

### 3.2 敏感字段不回显

`GET /api/config` 过滤机密字段：

```python
_SECRET_KEYS = ("secret", "admin_password", "ai_api_key")
```

- `secret` / `admin_password` 完全不返回；
- `ai_api_key` 有值时返回 `"******"`。

插件端 `ai_get_config` 同样把 `ai_api_key` 掩码为 `******`；保存时传入
`******` 或空则**不覆盖**。

> 例外：宝塔插件端有两个方法会返回明文管理员密码供回显——
> `get_admin`（设置页账号回显）与 `get_waf_info`（概览页「管理面板账号」旁显示
> 账号/密码，带显示/隐藏切换）。二者都运行在**已登录的宝塔面板**上下文中
> （继承面板鉴权），并非独立网络暴露面；独立 Web 端则**从不**返回明文密码。

### 3.3 配置写入防损坏（`_set_cfg`）

插件端 `_set_cfg` 在**读取失败（文件损坏 / 并发写坏）时拒绝保存**，绝不覆盖——
避免把 `secret` / `admin_password` / `ai_api_key` 一并抹除。若缺 `secret` 则用应用
默认值补齐（生成新 secret）后再写。

## 4. 网络暴露面

| 路径 | 是否需要登录 | 说明 |
|---|---|---|
| `POST /frp/handler` | **否** | frps 回调，始终放行（含 `web_enabled=false` 时） |
| `GET /`、`/index.html` | 否（仅静态页） | 登录页/SPA |
| `POST /api/login` | 否 | 登录接口（有限速） |
| `/api/*`（其余） | **是** | 需有效会话 Cookie |
| `web_enabled=false` | —— | `/`、`/index.html`、`/api/*` 一律 `403` |

> 建议：
> - 管理面板默认监听 `0.0.0.0:7080`，**尽量限制来源**（安全组 / 宝塔防火墙仅放行可信 IP）；
> - 或关闭网页端（`web_toggle`），仅通过宝塔插件端管理（插件端不走 7080）。

## 5. 请求处理的安全加固

- 请求体上限 **2MB**（`_body()` 超限抛错），防超大请求耗尽内存；
- socket `timeout=30`，缓解 slowloris 慢连接；
- 静态资源路径做**目录穿越防护**（`os.path.abspath` 前缀校验）；
- 默认访问日志静音（`log_message` 空实现），仅记录关键事件到 `frpwaf.log`；
- 决策异常时**放行**并打印堆栈（fail-open，避免 WAF 小 bug 拖垮业务）；
  进程不可达则由 frps 的 fail-closed 兜底（见 [03-工作原理与准入决策.md](03-工作原理与准入决策.md)）。

## 6. 运行日志中的隐私

- 登录失败只记「来源 IP + 用户名」，不记密码；
- 拒绝连接记「IP + 代理 + 原因」；
- **不打印任何密钥 / token**。

### 6.1 登录页与未登录访问

- 未登录访问 `/` 返回 `web/index.html`（SPA），前端探测 `/api/overview`：
  成功则进入主界面，`401` 则显示登录框。**未登录不会返回任何业务数据**。
- 登录接口 `/api/login` 对**任意来源**开放（否则无法登录），但受**登录限速**保护
  （见 §1.4）；失败响应前 `sleep(0.3)` 降低爆破速率。
- 独立面板「修改管理员账号」需**校验原密码**（`old` 必填），未登录无法调用。

## 7. 安全清单（部署建议）

1. 立即修改默认 `admin`/`123456`；
2. 限制 7080 端口的来源，或关闭网页端；
3. 定期检查「连接日志」「封禁管理」；
4. AI 密钥仅保存在 `600` 的配置文件里，不在面板回显；
5. 内核封禁开启（`fw_sync_enabled`）以在内核层丢包；
6. 如需对外，建议前置 HTTPS 反代并设 `X-Forwarded-Proto`（此时 Cookie 会自动加 `Secure`）。
