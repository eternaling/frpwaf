# 验证计划：运行日志噪声修复

- 关联任务：docs/tasks/active/task-20261001-171500-日志噪声修复.md
- 日期：2026-10-01
- 环境：本地 Windows（Python 3.12）+ 隔离实例（FRPWAF_HOME 临时目录）

## 验证目标

1. 客户端半途断开连接（模拟扫描器 `ConnectionResetError`）不再产生完整 traceback，
   日志中至多出现一条限流提示行。
2. 正常 HTTP 请求（登录页、回调）不受影响，仍正常响应。
3. 真实服务器错误（非断连类）仍被记录，不静默。
4. `python -m py_compile app/*.py frpwaf_main.py` 通过。

## 用例清单

| # | 用例 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|---|
| 1 | 半途断开 TCP | 隔离实例运行中 | 建立 TCP 连接后立即 RST 关闭，重复 5 次 | 无 traceback；至多 1 条限流提示 |
| 2 | 正常 GET / | 同上 | `urllib` 请求 `/` | 200 返回登录页 |
| 3 | 正常回调 | 同上 | POST `/frp/handler` 合法 JSON | `{"reject": false, ...}` |
| 4 | 非法 JSON 回调 | 同上 | POST 非 JSON 体 | 正常返回，无 traceback |
| 5 | 真实内部错误 | 同上 | 请求不存在的 API 方法（已登录后） | 404 JSON，无堆栈泄漏 |
| 6 | 慢连接超时 | 同上 | 建立连接不发数据，等待 timeout | 无 traceback（超时属断连类） |

## 回归范围

- 决策链（回调仍走 engine.decide）
- 静态页与登录 API
- 日志写入（`_log` 业务日志仍在）
