## 7. 不采纳项及理由

| 内容 | 理由 |
|---|---|
| 新建 `.pi/skills/` | pi 原生发现项目 `.agents/skills`；再建会重复加载并触发技能名冲突 |
| 在 `.pi/settings.json` 声明 skills | 同上，pi 对重名技能只保留首个并告警 |
| 照搬 Claude 的 `hooks.json` 机制到 pi | pi 无 hooks.json，机制不同，只能事件化改写 |
| pi SessionStart 用 `systemPrompt` 覆盖 | 会替换整段系统提示且不落盘；改用自定义消息（可验证、非侵入） |
| 各端 hook 保留独立规则副本 | 违反单一真源；规则漂移即防护强度取决于最弱一端 |
| 让 `test-hooks.cjs` 依赖 pi 运行时跑真实事件 | 慢且依赖 LLM；改为「处理逻辑下沉到 `pi-handlers.cjs` + 纯 Node 直调」 |
