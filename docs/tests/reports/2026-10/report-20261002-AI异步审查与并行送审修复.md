# 验证报告：立即审查按钮卡死与送审碎片化修复（Bug L）

- 关联任务：`docs/tasks/archive/2026-10/task-20261002-104500-AI大批量送审截断修复与保存按钮.md`
- 执行日期：2026-10-02
- 结论：通过

## 问题背景

用户实机反馈：点击「立即审查一次」后按钮一直停在「审查中…」；且观察网关日志
像是「一个一个 IP」送审。根因：插件端同步执行审查（大批量超时 → 回调永不返回）；
二分重试拆到 1 条/批 + 批次串行。

## 修复内容

| 层 | 改动 |
|---|---|
| 插件端 `frpwaf_main.py` | `ai_run_now` 只写 `ai_run_requested`（严格递增）并立即返回；新增 `ai_status` 轮询接口（running/pending/stale/finished） |
| daemon `app/ai.py` | `loop_forever` 消费请求（`ai_run_consumed` 游标，待处理时 2s 快轮询）；`_BATCH_SIZE` 100；波内并行 `_MAX_WORKERS=3`；`_MIN_SPLIT=5`；`review()` 互斥 + 状态机（`ai_review_state`/`ai_last_ok`，finally 清空） |
| 前端 `index.html` | `fwAiRun` 提交后轮询 `ai_status`（2s/次，最多 15 分钟），完成后恢复按钮并弹结果；页面刷新/切回 AI 页自动恢复轮询；beforeunload 清理定时器 |
| `app/config.py` | 新增 `ai_last_ok` / `ai_run_requested` / `ai_run_consumed` / `ai_review_state` / `ai_review_started` |
