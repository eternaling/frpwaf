## 1. 版本号约定

- 版本号同时写在两处，**必须保持一致**：
  - `app/__init__.py` 的 `__version__`
  - `info.json` 的 `"versions"`
- 守护进程 `server_version = "frpwaf/" + __version__`。
- 当前版本：**1.3.10**。

## 5. 版本号变更点

改版本时需同步：

1. `app/__init__.py`：`__version__ = "x.y.z"`
2. `info.json`：`"versions": "x.y.z"`（并按需更新 `"date"`）
3. `git tag v x.y.z` 并推送；
4. **Gitea 创建 Release**（tag 选 `v x.y.z`）并上传成品包 `frpwaf-x.y.z.zip`
   （从该 tag 克隆后 `bash build.sh zip` 构建，勿直接打包 Windows 工作区——
   避免 CRLF 行尾混入）。

> **文档同步**：发布新版本后，请同步更新
> [README.md](README.md) 顶部「当前版本」、本文件 §2 版本演进表，以及
> [12-Bug修复记录.md](12-Bug修复记录.md) 的 Bug ↔ 版本对应表。
