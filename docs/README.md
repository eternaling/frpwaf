## 一句话速览

FRP WAF 通过 frp 的 `httpPlugins` 钩子（`NewUserConn`）对**访问 frps 代理端口的来源 IP**
做黑/白名单、手动/自动封禁、**限速**，并可把封禁下发到内核（ipset+iptables）实现**内核层丢包**；
同时把宝塔官方「frp管理器」的 frps/frpc 管理能力并入，并提供独立管理面板与 AI 自动 IP 审查。

## 功能总览

| 功能 | 说明 | 主要文档 |
|---|---|---|
| IP 黑/白名单 | 支持单 IP 与 CIDR，白名单优先，黑白可同 CIDR 共存 | 03 / 04 |
| 手动封禁 / 解封 | 永久黑名单 与 临时封禁（带到期时间，自动解除） | 04 / 07 |
| 自动封禁 | 按窗口内连接次数阈值自动封禁（默认关闭，防误封） | 03 |
| 单 IP 限速 | 每秒新连接数上限（默认关闭） | 03 |
| 连接审计日志 | 记录每次连接的 IP/端口/代理/动作/原因，含归属地 | 04 / 07 |
| 内核级封禁 | 同步到 ipset + iptables，内核层丢包（白名单差集） | 05 |
| frp 服务端/客户端管理 | frps/frpc 安装、升级、配置、启停、日志、回滚 | 06 |
| frps 集成 | 一键注入 `[[httpPlugins]]` 回调配置 | 06 / 07 |
| AI 自动 IP 审查 | 高频来源 IP 交大模型判定，可选自动封禁 | 08 |
| IP 归属地查询 | 离线 GeoLite2 查询 + 高频来源 IP | 07 |
| 独立管理面板 | 7080 端口的 Web SPA（可开关） | 07 / 09 |
| 私有包加载 | 面板常驻进程内以 `frpwaf_app` 隔离加载运行代码 | 07 / 11 |

## 两套面板的差异（重要）

| 能力 | 宝塔插件端（`index.html`） | 独立 Web 端（`web/index.html`） |
|---|---|---|
| 登录 | 继承宝塔面板登录态，无需单独登录 | 独立登录（默认 `admin`/`123456`） |
| 概览 / 名单 / 连接日志 / 封禁 / 归属 / 代理统计 / 设置 | ✅ | ✅ |
| 内核封禁（状态/同步） | ✅（「IP 名单 / 封禁」页内） | ❌（**无**该 UI；用插件端） |
| AI 审查配置与结果 | ✅（「AI 审查」页） | ❌（**无**该 UI；用插件端） |
| frp 管理（frps/frpc） | ✅（「frp 管理」页） | ❌（**无**该 UI；用插件端） |
| frps 集成（注入回调） | ✅（「frps 集成」页） | ❌（**无**该 UI；用插件端） |
| 服务控制（启停/安装更新/卸载） | ✅ | ❌ |
| 网页端开关 / 改端口 | ✅ | ❌ |
| 修改管理员账号 | ✅ | ✅ |

> 独立 Web 端定位为「**轻量只读 + 日常名单/封禁操作**」，重操作（frp 管理、AI、内核封禁、
> 服务控制）集中在**宝塔插件端**。两端共享同一份 `data/`，数据一致。
> 注：Web 端无「注入/移除 frps 回调」按钮——回调用插件端「frps 集成 → 注入」，
> 移除需走**卸载**（会自动移除回调，见 [14](14-运维注意事项与约束.md) §2.2）。

## 关键路径速查

| 项 | 路径 / 值 |
|---|---|
| 项目源码 & 运行目录 | `/opt/frpwaf` |
| 宝塔插件安装位置 | `/www/server/panel/plugin/frpwaf` |
| 服务脚本 | `/etc/init.d/frpwaf` |
| 运行时数据 | `/opt/frpwaf/data`（`frpwaf.db` / `frpwaf.json` / `frpwaf.log` / `frpwaf.pid`） |
| 管理面板 | `http://<服务器IP>:7080/`（默认 `admin` / `123456`） |
| frp 回调地址 | `http://127.0.0.1:7080/frp/handler` |
| 内核集合 | ipset `frpwaf_block` / `frpwaf_block6`；iptables 链 `FRPWAF_BLOCK` |
| 代码规模 | `app/*.py` + `frpwaf_main.py` + 两个 `index.html` 合计约 **6200 行** |
