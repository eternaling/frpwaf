# 07 · 管理面板与插件功能

本项目有两套管理界面：

1. **宝塔插件端**（`frpwaf_main.py` + `index.html`）——在宝塔面板里点插件进入，
   走宝塔 `public` 接口，无需单独登录（继承面板登录态）。
2. **独立 Web 面板**（`app/daemon.py` + `web/index.html`）——守护进程在 `7080`
   端口直接提供的 SPA，需要独立登录（默认 `admin` / `123456`）。

两者共享同一份 `data/frpwaf.json` 与 `data/frpwaf.db`，功能高度对齐。

---

## 一、宝塔插件端

### 1.1 路由机制

宝塔插件请求形如：

```
POST /plugin?action=a&name=frpwaf&s=<method>   （或 GET，视方法而定）
```

`frpwaf_main.py` 暴露 `frpwaf_main` 类，方法名即 `s=<method>`。

> **重要坑（已在代码中规避）**：宝塔路由固定携带 `action=a`，它会**污染**
> `get.action` 字段。因此凡是「按 action 过滤」的参数一律改用别的名字：
> 连接日志用 `log_action`，代理筛选用 `log_proxy`。否则「按动作筛选日志」永远查不到数据。

### 1.2 菜单与页面

插件端 `index.html` 左侧菜单（`data-item`）：

| 菜单 | 说明 |
|---|---|
| 概览 | 今日连接/拦截/独立 IP/生效封禁/黑白名单数 + 运行信息 + **服务控制（启停/重启/安装更新网页端/卸载）** + **网页端开关/改端口** + 最近连接（最新 15 条） |
| IP 名单 / 封禁 | 黑/白名单增删、批量导入、临时/永久封禁与解禁、**一键解封全部黑名单 / 解封全部临时封禁（二次确认）**、**内核级封禁（状态/立即同步）** |
| AI 审查 | AI 接口配置、测试连接、**立即审查（异步提交 + 轮询进度，按钮不卡死）**、分级处置开关（疑似/SSH 从严）、**审查策略卡片（窗口/阈值/上限等，含独立「保存策略」按钮）**、审查结果（最近 200 条，含攻击类型与动作） |
| 连接日志 | 审计日志（IP/动作/代理筛选 + 分页），支持清空；**突发观测卡片**（按代理聚合的实时内存统计、定性标签、冷却剩余）与**原始/聚合视图切换**（1h/6h/24h） |
| 代理统计 | 每个代理的累计连接/拒绝数（按总连接数排序） |
| frp 管理 | frps/frpc（下拉切换）服务状态/启停、版本管理（安装升级/回滚/检查最新版/卸载）、配置修改（结构化/原文/校验/一键放行端口）、运行日志 |
| frps 集成 | 查看 frps 状态与 `frps.toml` 原文、是否已注入；**一键注入** `[[httpPlugins]]` 并重启 frps |
| IP 归属查询 | 单 IP 归属地查询 + 高频来源 IP |
| 设置 | 策略开关（黑/白/自动封禁/限速/内核封禁/AI）、阈值参数、**攻击类型自动封禁（CC/端口扫描/敏感服务爆破三组独立开关与参数，默认开启；卡片内自带「保存策略 / 重新加载」按钮）**、**代理级冷却拦截（分布式突发处置，默认关闭，含误伤提示）**、管理员账号 |
| 运行日志 | `data/frpwaf.log` |

> 「内核级封禁」的**状态查看与「立即同步」按钮**位于插件端「IP 名单 / 封禁」页内的
> 一张卡片里（独立 Web 端没有该卡片）。

### 1.3 主要插件方法（`s=`）

**状态 / 安装**

| 方法 | 作用 |
|---|---|
| `get_waf_info` | WAF 运行/安装状态、面板 URL、端口、frps 是否已注入（账号回显，密码为掩码 `******`） |
| `install_waf` | 安装/更新网页端（同步 `app/`、`web/` 到 `/opt/frpwaf`，装 init，`restart`，同步内核） |
| `reinstall_waf` | 卸载后重装，并**重新注入** frps 回调（卸载会移除插件块） |
| `uninstall_waf` | 停服务、清理内核、移除 frps 回调并重启 frps、去自启、删 init |
| `waf_admin` | 启动/停止/重启 WAF（`status=start/stop/restart`） |

**网页端开关 / 换端口**

| 方法 | 作用 |
|---|---|
| `web_toggle` | 开/关网页端（`enabled=1/0`）；关闭仅屏蔽网页与 API，**回调与防护照常** |
| `set_web_port` | 改面板端口：校验占用 → 写配置 → 同步 `frps.toml` 回调地址 → 重启 WAF → 探测监听 → 失败回滚 → 重启 frps |

**frps 集成**

| 方法 | 作用 |
|---|---|
| `get_frps_status` | frps 运行状态 + `frps.toml` 原文 + 是否已含 frpwaf |
| `apply_to_frps` | 注入 `[[httpPlugins]]` 并重启 frps（已注入则跳过） |

**frp 管理**：见 [06-frp服务端客户端管理.md](06-frp服务端客户端管理.md) §10。

**名单 / 封禁**

| 方法 | 作用 |
|---|---|
| `list_ips` | 名单列表（`type=black/white`，附归属地；返回上限 `PANEL_LIST_CAP=5000`） |
| `add_ip_entry` | 添加名单条目（`cidr`/`list_type`/`remark`） |
| `del_ip_entry` | 按 id 删除名单条目 |
| `batch_import_ips` | 批量导入（每行 `cidr[,备注]`） |
| `list_bans` | 永久黑名单 + 生效临时封禁 |
| `ban_ip` | 封禁（`mode=perm` 入黑名单 / `mode=temp` 临时封禁） |
| `unban_ip` | 解禁（`kind=perm` 删黑名单 / `kind=temp` 释放临时封禁） |
| `unban_all_black` | **一键解封全部黑名单**（误封恢复；刷新规则缓存 + 内核同步，白名单不受影响） |
| `unban_all_temp` | **一键解封全部生效中的临时封禁**（与黑名单解封独立；触发内核同步） |
| `ban_history` | 封禁历史 |

**日志 / 统计 / 归属**

| 方法 | 作用 |
|---|---|
| `conn_logs` | 连接日志（`log_action`/`log_proxy`/`ip` + 分页） |
| `log_proxy_list` | 日志中出现过的代理名（筛选下拉） |
| `logs_summary` | 按代理聚合最近窗口（`window`，钳制 60~86400 秒）：连接数/独立 IP/仅 1 次占比/被拒 |
| `burst_status` | 突发观测快照（代理级指标 + 定性 + 冷却剩余）与冷却阈值配置；读守护进程每 10s 落盘的 `data/burst_snapshot.json`（跨进程共享，>30s 未更新返回 `stale=true`） |
| `purge_conn_logs` | 清空连接日志 |
| `proxy_stats` | 代理统计 |
| `geo_query` | 单 IP 归属地 |
| `geo_top` | 高频来源 IP |
| `geo_db_info` | 归属地库状态 |
| `get_log` / `clear_log` | 运行日志读取/清空 |

**策略 / 内核 / 账号**

| 方法 | 作用 |
|---|---|
| `waf_overview` | 概览统计 |
| `get_policy` / `save_policy` | 准入策略读写 |
| `kernban_status` / `kernban_sync` | 内核封禁状态 / 手动同步（关闭态清理残留） |
| `get_admin` | 读取管理员账号（用户名 + 密码**掩码 `******`**，供设置页回显；不回显明文） |
| `change_admin_pwd` | 改账号（`old`/`new`/`new_user`/`old_user`） |

**AI**：见 [08-AI自动IP审查.md](08-AI自动IP审查.md)。

### 1.4 私有包加载机制

插件后端**不能**用通用包名 `app` 导入运行代码——面板进程里已有面板自身的 `app` 包，
会冲突（`ModuleNotFoundError: No module named 'app.frp'`）。故用私有包名 **`frpwaf_app`**
经 `importlib.util.spec_from_file_location(..., submodule_search_locations=[pkg_dir])` 加载。

- 包目录优先 `/opt/frpwaf/app`，回退插件目录 `app/`；找不到时抛**中文** `FileNotFoundError`。
- `_app(modname)` 会比对 `app/*.py` 的 mtime 签名，源码变更时**丢弃旧包重新导入**
  （面板常驻，否则会一直跑内存里的旧代码）。
- `_load_app_pkg()` 还会校验已注册包的 `__path__` 是否指向当前选定目录，被顶替时重建。

## 二、独立 Web 面板

### 2.1 访问

```
http://<服务器IP>:7080/
默认账号：admin / 123456   （安装后请立即修改）
```

由 `app/daemon.py`（`ThreadingHTTPServer`）提供：`/` 返回 `web/index.html`，
`/api/*` 提供管理接口，`/frp/handler` 是 frps 回调。

### 2.2 顶部导航（`data-tab`）

| Tab | 功能 |
|---|---|
| 概览 | 统计卡片 + 系统信息（含回调地址）+ 最近连接 |
| IP 名单 | 黑/白名单增删、批量导入、按类型筛选（黑/白/全部）、**解封全部黑名单**（二次确认） |
| 连接日志 | 审计日志（IP/动作/代理筛选 + 分页）、清空；**突发观测卡片**（按代理聚合的实时内存统计 + 定性标签 + 冷却剩余）与**原始/聚合视图切换**（1h/6h/24h） |
| 封禁管理 | 生效封禁 + 历史、手动封禁、解封、**解封全部临时封禁**（二次确认） |
| IP 归属查询 | 单 IP 查询 + 高频来源 IP |
| 代理统计 | 代理累计统计 |
| 设置 | 准入策略开关（黑/白/自动封禁/限速/内核封禁）、阈值参数、**攻击类型自动封禁（CC/端口扫描/敏感服务爆破三组独立开关与参数，默认开启）**、**代理级冷却拦截（分布式突发处置，默认关闭，含误伤提示）**、修改账号 |

> **Web 端不含**：内核封禁状态/同步按钮、AI 审查、frp 管理、frps 集成、
> 服务控制（启停/安装更新/卸载）、网页端开关/改端口。
> 这些重操作集中在**宝塔插件端**（见 [README「两套面板的差异」](README.md)）。
> Web 端定位为「轻量只读 + 日常名单/封禁操作」。
>
> 说明：`web/index.html` 的设置页含 `fw_sync_enabled`（内核封禁）**开关**，
> 但**没有**独立的「内核封禁」页；内核封禁的**状态查看与手动同步**在插件端
> 「IP 名单 / 封禁」页内。

### 2.3 网页端开关

配置项 `web_enabled`（默认 `true`）：

- 关闭后：`/`、`/index.html`、`/api/*` 一律返回 `403 网页端已关闭`；
- **不受影响**：`/frp/handler` 回调与 WAF 防护照常运行；
- 可从宝塔插件端随时重新开启（`web_toggle`）。

> 设计意图：允许「只用 WAF 防护、不暴露管理面板」，降低攻击面；同时保证关闭网页端
> **不会**触发 frps 的 fail-closed（回调仍在）。

## 三、两端的对应关系

> 下表为**后端能力**的对应关系。注意：独立 Web 端的**页面**只暴露其中一部分
> （见 §2.2 与 [README「两套面板的差异」](README.md)）——带「※」的接口虽然存在，
> 但 **Web 端没有对应 UI**，需从宝塔插件端操作。

| 功能 | 插件端方法 | Web API |
|---|---|---|
| 概览 | `waf_overview` | `GET /api/overview` |
| 策略读写 | `get_policy`/`save_policy` | `GET/POST /api/config` |
| 名单 | `list_ips`/`add_ip_entry`/`del_ip_entry`/`batch_import_ips`/`unban_all_black` | `GET/POST /api/iplist`（POST `action=clear_black`） |
| 连接日志 | `conn_logs`/`purge_conn_logs` | `GET/POST /api/logs` |
| 代理名 | `log_proxy_list` | `GET /api/logs/proxies` |
| 封禁 | `list_bans`/`ban_ip`/`unban_ip`/`unban_all_temp`/`ban_history` | `GET/POST /api/bans`（POST `action=unban_all`） |
| 代理统计 | `proxy_stats` | `GET /api/proxies` |
| 归属查询 | `geo_query`/`geo_top`/`geo_db_info` | `GET /api/geo`、`/api/geo/db` |
| 内核封禁 | `kernban_status`/`kernban_sync` | `GET /api/kernban`、`POST /api/kernban/sync` ※ |
| AI | `ai_get_config`/`ai_save_config`/`ai_test`/`ai_run_now`/`ai_status`/`ai_results` | `POST /api/ai/review`、`/api/ai/test`、`GET /api/ai/results` ※ |
| 账号 | `get_admin`/`change_admin_pwd` | `GET /api/config`、`POST /api/password` |
| 版本 | （页面内嵌） | `GET /api/version` |
| frp 管理 / frps 集成 / 服务控制 | `frp_*` / `get_frps_status`/`apply_to_frps` / `install_waf` 等 | **无**（仅插件端） |

> 两端逻辑一致，均最终落到同一份 `store` / `config`。插件端因继承宝塔登录态，
> 直接读写配置；Web 端需独立会话（见 [09-认证与安全.md](09-认证与安全.md)）。
